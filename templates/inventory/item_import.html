Steps to Import

Step 1

Create an Excel file (or CSV) with the following format.

Download Sample or as CSV
item_name* item_class* uom* price purchase_price item_bar_code
Item 1Raw MaterialKg120.0095.008901234567890
Item 2PackingEach45.5030.00
Item 3Finished GoodsBag2040.001800.00

* required. item_class and uom must already exist — give the name or the code. The item code is generated from the category, the same way the Add Item screen does it.

Step 2

Upload the file (.xlsx or .csv) using the box on the right. The older .xls format is not read — re-save it as .xlsx.

Step 3

Press Import. Every row is checked first — if any row is wrong, nothing is saved and each problem is listed back here.

Imported items start at zero stock. Move quantities in with a Stock Adjustment or a goods receipt, so the item ledger and the Inventory account stay in step.
