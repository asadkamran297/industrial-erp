# UI / UX Guidelines

The portal must feel official, calm, and obvious.

## Direction

- Clean layouts, strong spacing, readable type, and clear hierarchy.
- Avoid Django Admin patterns for the main product.
- Use simple labels and direct language for non-technical users.
- Every screen should explain itself visually without long instructions.
- Keep cards for individual repeated items or framed tools.
- Support mobile and desktop from the beginning.

## Components

Use `templates/components/` for fields, cards, page headers, alerts, table controls, empty states, and status badges.
